Enterprise Device Owner & Admin Setup
Method 1: Local ADB on Phone (NO LAPTOP REQUIRED)
Works on Android 11+ directly on the phone screen without any computer:
  1. Enable Developer Options (Settings > About Phone > Tap Build Number 7 times).
  2. Go to Developer Options > Turn ON Wireless Debugging.
  3. Install LADB or Bugjaeger on the phone. Pair using the 6-digit code.
  4. Execute the command directly on the phone:
dpm set-device-owner com.simtool/.CompanyDeviceAdminReceiver
⚠️ Tip: Temporarily remove Google accounts from Settings > Accounts before executing, then add them back immediately after.
Method 2: From Another Android Phone (NO LAPTOP REQUIRED)
Install free Bugjaeger on a friend's Android phone. Connect both phones with a USB cable. Open Bugjaeger > Commands tab > run dpm set-device-owner com.simtool/.CompanyDeviceAdminReceiver. Takes 10 seconds!
Method 3: 1-Tap Device Administrator (Built into App Settings!)
Don't want to use any terminal or commands? Inside the phone app Settings > Company Asset Protection, tap "🛡️ ACTIVATE PROTECTION". This blocks standard uninstallation, enables remote screen lock, remote PIN reset, and remote data wipe immediately. Zero laptop, zero reset!
